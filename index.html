사용법
복붙 모드 (키 없이, 폰에서 바로)
GPT 차례가 되면 카드가 뜹니다. ① 복사 → ② ChatGPT 앱에 붙여넣기 → ③ GPT 답변을 다시 이 칸에 붙여넣으면 대화에 끼워 넣어집니다. 지금까지의 대화 전체가 함께 복사되니 GPT도 맥락을 알고 답합니다.
API 모드 (GPT가 자동 답변)
설정에 OpenAI API 키를 넣으면 GPT가 바로 답합니다. 단, 클로드 앱 안에서 열린 페이지는 보안 정책상 외부 서버 요청이 막혀 있어서 이 모드가 동작하지 않습니다. 이 파일을 폰에 저장해 크롬에서 열면(또는 PC 브라우저) 자동 답변이 됩니다.
클로드
클로드 앱 안에서 열었을 때는 키 없이 바로 답합니다. 파일로 열었을 때는 Anthropic API 키를 넣거나, 답변자를 "GPT만"으로 두고 클로드 쪽은 이 채팅창에서 직접 이야기하면 됩니다.
