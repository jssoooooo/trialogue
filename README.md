# 삼자대화 — 나 + 클로드 + GPT

나와 Claude와 GPT가 한 방에서 대화하는 설치형 웹앱(PWA). 서버 없이 브라우저에서만 돌아갑니다.

## 기능

- **3자 대화** — 내가 질문하면 Claude와 GPT가 각자 답합니다. 답변자는 `둘 다 / 클로드만 / GPT만` 중 선택
- **자동 토론** — 주제를 주면 Claude와 GPT가 정해진 횟수만큼 주고받습니다
- **복붙 모드** — API 키가 없으면 대화 전체를 복사해 ChatGPT에 붙여넣고, 답변을 다시 가져오는 방식으로 쓸 수 있습니다
- **성격 설정** — 각자에게 다른 지시를 줄 수 있습니다
- **오프라인 실행** — 설치 후에는 네트워크 없이도 앱이 열립니다 (API 호출은 당연히 온라인 필요)

## 설치

1. GitHub Pages 주소를 Chrome으로 엽니다
2. 메뉴 → `앱 설치` 또는 `홈 화면에 추가`
3. 홈 화면 아이콘으로 실행 — 주소창 없는 전체화면으로 열립니다

## API 키

앱 안 ⚙ 설정에서 입력합니다.

| 참가자 | 필요한 것 | 없을 때 |
|---|---|---|
| GPT | OpenAI API 키 | 복붙 모드 |
| Claude | Anthropic API 키 | 복붙 모드 |

키는 **브라우저의 localStorage에만** 저장되며, 이 저장소에도 어떤 서버에도 전송되지 않습니다. API 호출은 브라우저에서 각 제공사로 직접 갑니다.

공용 기기에서는 키를 넣지 마세요. 브라우저 저장소에 평문으로 남습니다.

## 구성

```
index.html            앱 전체 (HTML + CSS + JS)
manifest.webmanifest  PWA 매니페스트
sw.js                 서비스 워커 (앱 파일만 캐시, API 호출은 통과)
icon-192.png          아이콘
icon-512.png          아이콘 (maskable)
apple-touch-icon.png  iOS 아이콘
```

의존성 없음. 빌드 과정 없음. `index.html`을 그대로 열어도 동작합니다.
